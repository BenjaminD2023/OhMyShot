# Keyboard reference

Every key OhMyShot answers once something of it is open. The shortcuts that start a capture are your own: set
them in Settings › Shortcuts, where this page is linked at the foot. While you choose an area, press **?** to
see the keys of what you are doing beside the screen's edge; Escape or any other key puts them away.

Keys marked *held* do their work while held down, during a drag or as it ends.

## Capture overlay

Capture Area (and its Copy, Save, Annotate, Pin, and Upload variants), Annotate Area, the Self-Timer's
choosing, Capture Text, Record Screen, and Scrolling Capture open the same overlay. A drag chooses an area;
the keys below only refine it.

| Key | What it does |
| --- | --- |
| Arrows | Move the crosshair one captured pixel, ten with Shift. During a drag, they move the corner being dragged. |
| Shift *held* | Keeps the area to a square, or to the shape set in Settings › Capture › Selecting › Shift keeps. |
| Option *held* | Grows the area from its center. In Capture Text, held as the drag ends, opens the OCR panel instead. |
| Command *held* | With Snap the selection to text on, places the edges freely until the mouse button goes up. |
| Space | Before a drag, switches between choosing an area and choosing a window. During a drag, moves the area. |
| W | Opens the window chooser (Capture Area and Record Screen). |
| Tab | Opens the size control, to type a size or keep a shape (Capture Area and Annotate Area). |
| L | Brings back the last area taken since OhMyShot opened (Capture Area, Annotate Area, All-In-One). |
| C | Copies the color under the crosshair and ends the capture; Option-C opens the color card instead (Capture Area, Annotate Area, the Self-Timer). |
| Delete | During a drag, starts the drag over. A right-click does the same. |
| ? | Shows these keys, or puts them away. |
| Escape | Cancels. |

### Choosing a window

After Space, or in a purpose that starts on windows:

| Key | What it does |
| --- | --- |
| Click | Captures the window under the pointer. |
| Shift-click | Adds a window to the selection, or takes it away (screenshots, Annotate Area, Capture Text). |
| Return | Captures the selected windows, or the one under the pointer. |
| Tab, Shift-Tab, `]`, `[` | Highlight the next or previous window. |
| Space | Goes back to dragging an area. |
| Scroll | Picks a part of the window under the pointer, taken as an area (Capture Area and Annotate Area, with Accessibility on). |

### The window chooser (W)

| Key | What it does |
| --- | --- |
| Left, Right | Switch apps. |
| Up, Down | Switch between the chosen app's windows. |
| Command-F | Shows search. |
| Command-R | Reads the list of windows again. |
| Return | Captures or records the window shown. |
| Escape | Closes search, then goes back to choosing (or cancels Capture Window). |

### The size control (Tab)

| Key | What it does |
| --- | --- |
| Return | Captures the area (Annotate Area marks it up in place). |
| Arrows | Move the area a point, ten with Shift. With Option, they move its right or bottom edge. |
| B | On a frozen screen, fits the area to the edges of what it holds. |
| B again, Command-Z | Put back the area as it was before B. |
| Tab | Goes to the width, to type it. In the fields, Return sets the size and Escape puts it back. |
| ? | Shows these keys. |
| Escape | Ends an adjustment, then cancels. |

## All-In-One

Before an area is chosen:

| Key | What it does |
| --- | --- |
| A | Area: a plain capture, and lets go of Text, Scrolling, or Record. |
| W | Opens the window chooser. |
| Space | Points at a window to capture. |
| F | Captures the whole screen. |
| O | Text: the next area is read and its text copied. |
| S | Scrolling: the next area becomes a scrolling capture. |
| R | Record: the next area is recorded. |
| M | Turns the overlay into Measure on the same frozen screen. |
| L, C, arrows, ?, Escape | As in the capture overlay. |

Once an area is framed:

| Key | What it does |
| --- | --- |
| Return, double-click | Captures the area. |
| Command-C, Command-S | Capture and copy, capture and save. |
| E, P, U | Capture and annotate, pin, or upload (U while a destination is set up). |
| O, S, R | Read its text, start a scrolling capture, record it. |
| F | Captures the whole display instead. |
| Arrows | Move the area a point, ten with Shift. With Option, they move its right or bottom edge. |
| B | On a frozen screen, fits the area to the edges of what it holds, as Measure fits a box. |
| B again, Command-Z | Put back the area as it was before B. |
| Tab | Goes to the width and height, to type them. |
| Q | Opens the next QR code's or barcode's card, when codes were found in the area. |
| ? | Shows these keys. |
| Escape | Ends an adjustment, then cancels. |

## Capture Text

As the capture overlay: drag over text, or Space to choose a window. Option held as the drag ends opens the
area in the OCR panel. Escape cancels.

## Pick Color

| Key | What it does |
| --- | --- |
| Click, Return, C | Copies the color under the crosshair and closes. |
| Option-click, Option-Return, Option-C | Opens the color card, with the color in every notation. |
| Arrows | Move the crosshair a pixel, ten with Shift. The keys follow the crosshair onto another display. |
| ? | Shows these keys. |
| Escape | Cancels. |

The color card, when opened from the keyboard: Command-C copies the lead notation, Tab moves through its
chips with Full Keyboard Access, and Escape closes it.

## Measure

| Key | What it does |
| --- | --- |
| Command-C | Copies the measurement; the ruler stays. |
| Return | Copies the measurement and closes. |
| Tab, U | Switch between points and pixels. |
| T | Cycles the edge tolerance. |
| `+` (or `=`), `-` | Raise or lower the edge tolerance. |
| C | Copies the color under the crosshair. |
| Arrows | Move the crosshair a pixel, ten with Shift. |
| Command, Shift, Option, or Control *held* | As a drag ends, keeps the box as drawn instead of fitting it. |
| ? | Shows these keys. |
| Escape | Cancels. |

See [measurement-snapping.md](measurement-snapping.md) for how boxes fit.

## Record Screen

Choosing is the capture overlay's: drag an area, click for the whole display, Space or W for a window. Once
the area is framed, Return (or a double-click inside) records and Escape ends an adjustment, then cancels.
While recording, press the Record Screen shortcut again to stop.

## Scrolling Capture

Once the area is framed, Return (or a double-click inside) starts and Escape cancels. While it runs, the keys
belong to the app being scrolled: press the Scrolling Capture shortcut again, or click Done, to finish.
Escape, a click, or scrolling by hand pauses Auto-scroll.

## Annotate Area (in place)

Before an area is chosen, the capture overlay's keys. Once it is marked up in place:

| Key | What it does |
| --- | --- |
| Tool keys | As in the editor, for the tools the in-place toolbar offers. |
| Delete | Deletes the selected marks. |
| Arrows | Move the selected marks a point, ten with Shift. |
| Command-Z, Shift-Command-Z | Undo, redo. |
| Return, Enter, double-click | Copy the marked-up area and finish. |
| Escape | Ends an adjustment, then puts the tool down, then cancels. |

## Quick Access card

A card takes the keys when its picture is clicked, or with the Control Quick Access shortcut (Settings ›
Shortcuts). The app in front stays in front.

| Key | What it does |
| --- | --- |
| Command-C | Copy |
| Command-S, Shift-Command-S | Save, Save As |
| Option-Command-S | Save All |
| Command-E | Annotate (Edit or Play for a recording) |
| Command-O | Open |
| Space | Quick Look; Space or Escape closes it |
| Shift-Command-T | Recognize Text |
| Shift-Command-P | Pin to Screen |
| Command-P | Print |
| Shift-Command-U | Upload to the default destination |
| Command-L, Command-R | Rotate left, rotate right |
| Command-Delete | Move to Trash (Delete alone does nothing) |
| Command-Z | Brings back a card moved to the Trash, within 5 seconds |
| Arrows | Up or Left to an older card, Down or Right to a newer one |
| Escape, Command-W | Close the card and hand the keys back |
| Option-Command-W | Close All |

## Pins

A pin takes the keys when clicked; a new pin never does.

| Key | What it does |
| --- | --- |
| Command-`=`, Command-`-` | Zoom in or out around the center. |
| Command-0 | Actual size. |
| Arrows | Move the pin a point, ten with Shift. |
| Command-C | Copies the selected text, else the picture, the text, or the hex. |
| Command-A | Selects all of the text. |
| Command-S, Shift-Command-S, Command-P | Save, Save As, Print (pictures). |
| Option-scroll | Sets the opacity. |
| Middle click | Closes the pin. |
| Escape | Clears a text selection, then closes the pin. |
| Command-W | Closes the pin. |

## Studio

A recording opened in its window. The arrows, I, O, Delete, and Escape work while the timeline has the keyboard
(click it).

| Key | What it does |
| --- | --- |
| Space | Plays or pauses. |
| Left Arrow, Right Arrow | Move the playhead; with Shift, a longer step. |
| Option-Left Arrow, Option-Right Arrow | Choose the previous or next edit. |
| I, O | Mark the start or end of a range. |
| Delete | Removes the range or the edit chosen. |
| Escape | Clears what is chosen on the timeline; while exporting, cancels the export. |

## Draw on Screen

1 to 6 choose a tool, T lets clicks through to the screen, Delete clears, Command-Z undoes, and Escape stops.

## Self-Timer

Press the shortcut that started the countdown again to cancel it.
