## Platform

macos

Native macOS app. Impeccable ships only iOS and Android platform references; the spirit of `ios.md` applies (system controls, semantic colors, SF Symbols, platform motion), but the macOS Human Interface Guidelines govern: menu bar residency, non-activating panels, keyboard-first workflows, pointer hover states, and Liquid Glass on macOS 26 and later. The mechanical design detector reads only HTML and CSS, so native surfaces are gated by the finish review alone.

## Stack

User's choice: native Swift 6 with SwiftUI and AppKit, minimum macOS 26 (APIs from macOS 26.4 and 27 are optional enhancements behind availability checks). The Xcode project is generated by XcodeGen from `project.yml`; almost all code lives in the local Swift package `Packages/OhMyShotKit`. Licensed GPL-3.0. Apple silicon only.

## Users

The author first: a developer on a multi-display Mac (a 6K external display plus the built-in XDR panel, so mixed scale factors and HDR) who captures, records, and extracts text many times a day, often from mixed Chinese and English content. Then open-source Mac users who want CleanShot X–level capture without paying for yearly updates or a subscription.

## Product Purpose

A complete, open-source macOS capture tool: screenshots, recordings, annotation, pinning, history, and sharing at CleanShot X parity, with OCR good enough to replace dedicated OCR apps, while costing nothing measurable in power when idle. Success means the author uses it as their only capture tool every day, and its idle CPU, wakeups, and memory are measured, published, and kept at target.

## Positioning

CleanShot X's completeness, plus a document-grade on-device OCR pipeline (layout and code indentation, tables, formulas and handwriting through optional model packs, translation drawn over the original text), plus a published, measured low-power commitment. Free and open source. Sharing uploads only to storage the user owns.

## Operating Context

Lives in the menu bar and is summoned by global shortcuts dozens of times a day. Two capture flows: CleanShot-style by default and in-place annotation (a toolbar beside the selection) on its own shortcut. In the default flow a capture is copied to the clipboard and shown as a Quick Access card in the corner of the screen; nothing is written to the Desktop or any folder until the user saves it (or turns on saving after capture), and the card leads on to the editor. Cards stay until they are closed; Settings can have them close by themselves (never saving anything unless asked to), and a card can be driven from the keyboard without the app coming forward. Every capture and recording is also kept in Capture History for a retention the user picks (never, 1 day, 3 days, 1 week by default, 1 month), from where it can be restored to Quick Access. Output goes to the clipboard, Finder, chat apps, documents, and issue trackers. OCR targets code, documents, papers, chat screenshots, and Chinese, Japanese, and Korean interfaces.

## Capabilities and Constraints

- Feature parity with CleanShot X 5.x: capture modes, Quick Access overlay, annotation editor, pins, screen recording including Studio-style auto-zoom, scrolling capture, capture history, and URL-scheme automation compatible with CleanShot's command names.
- Beyond CleanShot: pixel ruler and screen color picker, pinning anything from the clipboard with text selection on pins and history, translation overlay, OCR tables to Markdown/CSV, OCR-driven redaction suggestions, and text search across capture history.
- Capture History keeps every screenshot as a lossless PNG of the capture as it was taken, because marking up, OCR, redaction suggestions, and restoring depend on it. The file format (PNG, JPEG, HEIC), Retina to 1×, sRGB, the 1 px border, and the file name apply to the copy that leaves the app: saved, dragged out, uploaded, handed to a shortcut, or on the clipboard. The defaults write what the history holds.
- Not sandboxed and not on the App Store; distributed through GitHub.
- No first-party server. Sharing uploads only to user-provided storage (S3-compatible, Cloudflare R2, WebDAV, custom HTTP). Server-side cloud features (password-protected links, expiry, comments, transcription, custom domains, teams) are out of scope.
- A Studio recording keeps the keys pressed, so Studio can show them after the recording: by default whenever Input Monitoring is already on, and under All keys what was typed is stored as typed in the project on this Mac (never sent anywhere, never from a password field or while the system keeps keystrokes private, and from a window recorded on its own only when Show Keystrokes was on). Settings › Recording › Studio › Keep the keys pressed turns it off, and Shortcuts only keeps no typing. Input Monitoring is never asked for by it. Left on by default (2026-10-17) because without it Studio could not add keystrokes to a recording made with Show Keystrokes off; revisit if it troubles users.
- Processing is on-device by default. Cloud OCR models run only with a user-supplied API key the user explicitly enables.
- Apple Intelligence (Foundation Models) reports the author's machine as not eligible; it may enhance features but is never required.
- UI languages: English and Simplified Chinese.
- Idle power targets: 0.0% CPU, fewer than 1 wakeup per second, memory footprint under 30 MB after launch and under 60 MB after use.

## Brand Commitments

Name: OhMyShot. It collides with an existing product (ohmyshot.app); the user accepted that risk.

Look and feel: native macOS at CleanShot X's level of craft: bright, soft, and rounded. System colors and materials, continuous-corner cards with soft shadows, white capsules for readings and actions, Liquid Glass only on small HUDs. The user set this direction on 2026-10-07 after rejecting the first visual world ("Contact Sheet": dark film-edge strip, numbered frames joined into one strip, darkroom accents) as hard, heavy, and Linux-like. Frame numbers, joined strips, and darkroom motifs stay out.

## Evidence on Hand

No logo or marketing copy yet. Measured latency and idle-power numbers are recorded in `Docs/perf.md`; publish only those, and do not invent user counts, benchmark numbers, or competitive comparisons.

## Product Principles

1. Invisible until summoned: zero idle cost is a feature.
2. Text in pixels is first-class data.
3. Native or nothing: platform controls, conventions, and permission behavior.
4. Every capture is one action away from where it needs to go.
5. Private by default: on-device first, and anything that leaves the Mac is explicit.

## Accessibility & Inclusion

Every control has a VoiceOver label, every workflow can be completed from the keyboard, and Reduce Motion, Reduce Transparency, and Increase Contrast are respected.
