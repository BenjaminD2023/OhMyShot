# Release notes

## [Unreleased]

### 最新の状態に

- **公式サイトから更新をダウンロード。** 更新情報とインストールファイルは OhMyShot の公式サイトから取得し、接続できない場合は GitHub を使用します。
- **見つけやすい更新通知。** 新しいバージョンをメニューの先頭に表示し、メニューバーのアイコンにも矢印を添えます。今すぐ更新するか、翌日に通知するかを選べます。

### 新しい更新内容ウインドウ

- 更新後に**更新内容**を自動表示。オフラインでも読めます。
- Markdown の見出し、リスト、リンク、強調、コードに対応し、バナーも追加できます。

### 更新のタイミングはあなた次第

- 起動時と6時間ごとに更新を確認します。ダウンロードと再起動の前には確認します。
