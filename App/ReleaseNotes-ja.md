## [0.5.0] - 2026-11-25

### キャプチャ、収録、スタジオ編集を強化

- **4方向スクロールと柔軟なセルフタイマー。** スクロールキャプチャが上下左右の4方向と速度調整に対応しました。セルフタイマーは画面上で `D` または `1`〜`5` により秒数を変更でき、カウントダウン中に `Esc` やクリックでキャンセルできます。
- **収録前マイク確認と収録中コントロール。** 収録前にライブマイクレベルを確認でき、収録中にマイクをライブミュート／解除したり、メニューバーから一時停止や画面への描画を切り替えたりできます。GIF作成ポップオーバーでフレームレートとサイズを選べます。
- **スタジオの波形、マスター音量、クロップ、プロジェクトパッケージ。** タイムラインに音声波形を表示し、マスター音量・ミュート・フェードイン／アウト・カット境界のマイクロフェードを追加しました。非破壊クロップ、速度区間やカット端のドラッグ／リサイズ、`J`/`K`/`L` シャトル再生、ピンチによるタイムライン拡大縮小、独立した `.omsstudio` パッケージの書き出し／読み込みに対応しました。

### 注釈、テキスト認識、翻訳の進化

- **より快適な注釈とコピー。** ツールのダブルクリックでロックでき、墨消しツールは描画後も手元に残ります。エディタ間の注釈コピー＆ペースト、合成画面からのスポイト、コピーして閉じる／閉じずにコピー（`⌘C`）、角丸や墨消し強度の調整、エディタからのテキスト認識やプリントに対応しました。
- **OCRパネルと翻訳レンズを強化。** OCRパネルで画像の拡大縮小・パン、表セルの直接編集とRFC-4180準拠CSV/TSV書き出し、数式のLaTeX区切り設定が可能になりました。翻訳レンズ内で翻訳先言語をすばやく切り替え、翻訳済みオーバーレイをコピー・保存・ピン留めできます。
- **認識言語とモデルミラー設定。** 「設定 › テキスト」で優先認識言語の指定、モデルパックごとの有効／無効切り替え、カスタムダウンロードミラーURLの設定ができます。

### 履歴、ピン、クイックアクセス、オートメーション

- **履歴・ピン・クイックアクセスの操作性向上。** 履歴に `⇧+矢印` の範囲選択、日付・アプリでの絞り込み、ディスク使用量表示、5秒以内のゴミ箱取り消し、並び替え可能な複数列コラージュを追加。クイックアクセスは画面の四隅配置と操作後の自動クローズに対応し、最近閉じたピンを最大5件まで変形・設定ごと復元できます。
- **ショートカット、URLスキーム、Raycast、共有拡張を拡充。** 範囲注釈、範囲翻訳、カラーピッカー、計測、画面描画、リプレイ保存、画像アップロード（URL返却）と対応Raycastコマンドを追加。macOS共有メニューから直接テキスト認識でき、4つのグローバルショートカットと拒否済み呼び出し元の管理にも対応しました。
- **コード認識と信頼性の修正。** 狭いガターの行番号除外と中国語・日本語コメントの `//` 保持を改善し、Retina DPIメタデータの埋め込みや、履歴削除時の `.studio` バンドル同時削除に対応しました。

## [0.4.0] - 2026-11-22

### スタジオでできる編集が増えました

- **速度、音量、ズームを調整。** 選んだ区間を 0.5× から 4× まで変速できます。システム音とマイクの音量は別々に調整でき、ズームはポインタを追わずに固定位置に合わせられます。
- **背景を変更。** カメラ映像の背景をぼかしたり人物だけを切り抜いたりできます。収録の背景には画像や収録自体をぼかした映像を使えます。書き出しにもプレビューと同じ効果が反映されます。
- **GIF の書き出し、MP4 と MOV の読み込み。** スタジオで編集した収録は GIF にできます。MP4 や MOV を収録ウインドウで開いて、トリミングしたり GIF を作ったりすることもできます。

### キャプチャ、注釈、共有

- **ルーペと消去。** 細部を最大 4× に拡大したり、周りの色で範囲を覆ったりできます。これらのマークを使ったプロジェクトには OhMyShot 0.4.0 以降が必要です。
- **その場でピン留めや共有。** 「範囲に注釈を付ける」からピン留めやアップロードができ、エディタからは共有もできます。アプリを開き直したときにピンを復元できます。
- **キャプチャ履歴を活用。** お気に入りは保持期限を過ぎても残ります。複数のキャプチャをまとめてドラッグや共有でき、履歴やクイックアクセスから認識パネルを開かずにテキストをコピーできます。
- **キー操作をその場で確認。** 範囲やウインドウの選択中は ? でキー操作を表示できます。静止した画面では B で枠を中の内容に合わせられます。

### より確実な墨消しと保存

- **墨消しの重なりを正しく反映。** 重ねたぼかしやモザイクはすでに墨消しされた画像を使い、ぼかし背景も墨消し後の画像から作ります。エディタ、書き出し、共有で同じ結果になります。
- **履歴に保存できなくても作業を残します。** その場で付けた注釈はエディタで開けます。履歴に追加できなかったリプレイのクリップも残ります。

## [0.3.0] - 2026-11-21

### オールインワンでウインドウを選択、そのまま計測

- **クリックでウインドウをキャプチャ。** オールインワンはポインタの下のウインドウをハイライトし、クリックするとそのウインドウを枠で囲んで、どのキャプチャにも使えます。ドラッグすれば今までどおり自由な範囲を選べます。
- **バーから計測。** M キーを押すと、静止した画面のまま計測を始められます。
- **何も選ばれていない状態で開始。** オールインワンは範囲が選ばれていない状態で開き、L キーで前回の範囲を呼び戻せます。

### 仕上がりの美しいスクリーンショット

- iShot のような**角丸とやわらかな影**をスクリーンショットに。「設定 › スクリーンショット › 背景」でオンにできます。

### 見たままに読み取るテキスト

- **行がばらばらになりません。** 「テキストをキャプチャ」は、ターミナルの一覧、設定の一覧、表の行を1行として読み取り、コード中の波かっこも正しく認識します。
- **ウルトラワイド画面もきれいに。** 文字の詰まったウルトラワイド画面でも、行が抜けたり重複したりしなくなりました。

### 作業内容を守ります

- **失敗しても何も失いません。** ゴミ箱に移せなかったキャプチャはキャプチャ履歴に残り、収録を置き換えるときは新しいファイルが用意できるまで元のファイルを残します。エディタは編集内容が保存されるまで閉じません。
- **収録が安全に止まります。** ディスクがいっぱいになったりファイルに書き込めなくなったりすると、収録はすぐに止まり、どこまで保存されたかを知らせます。スタジオは収録のドラフトを、すべて保存されるまで残します。
- **より強力な墨消し。** ぼかしとモザイクは、広い範囲ほど強くかかるようになりました。

### 使用状況データ

- **「使用状況データ」がデフォルトでオンになりました。** 送信するのは、1日ごとのスクリーンショット、収録、テキスト認識の回数と、アプリと macOS のバージョン、毎日変わるランダムな ID だけです。キャプチャ、認識したテキスト、ファイル名は送信しません。「設定 › 一般 › 使用状況データ」でオフにでき、その際に未送信の回数も削除されます。

## [0.2.0] - 2026-11-19

### 最新の状態に

- **公式サイトから更新をダウンロード。** 更新情報とインストールファイルは OhMyShot の公式サイトから取得し、接続できない場合は GitHub を使用します。
- **見つけやすい更新通知。** 新しいバージョンをメニューの先頭に表示し、メニューバーのアイコンにも矢印を添えます。今すぐ更新するか、翌日に通知するかを選べます。

### 新しい更新内容ウインドウ

- 更新後に**更新内容**を自動表示。オフラインでも読めます。
- Markdown の見出し、リスト、リンク、強調、コードに対応し、バナーも追加できます。

### 更新のタイミングはあなた次第

- 起動時と6時間ごとに更新を確認します。ダウンロードと再起動の前には確認します。
